시안 확인 페이지 만들기

고객에게 보낼 프로젝트 코드와 안내 파일(JSON)을 만들어 주는 내부용 도구예요. 이 페이지는 고객에게 보내지 마세요.

이 도구는 브라우저 안에서만 동작해요. 입력한 내용은 어디에도 전송되지 않아요. 만든 파일을 GitHub의 projects 폴더에 올려야 고객 페이지에 반영돼요.

1. 프로젝트 코드

2. 기본 정보

3. 3D 시안

4. 턴어라운드 렌더링

5. 제안서 PDF

6. 확인을 부탁드릴 내용

① 폴더 이름
코드에서 계산한 이름이에요. 코드 자체는 파일에 남지 않아요.
② 고객에게 보낼 것
페이지 주소(코드 없이)와 코드를 따로 보내시면 더 자연스러워요.
③ 올릴 파일
    ④ projects 폴더에 올릴 JSON
